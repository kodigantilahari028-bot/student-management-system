# Student Management System

A simple web-based Student Management System built with Node.js, HTML, CSS, and JavaScript.

## Features
- Add students with name, age, and course
- View student records
- Delete student records
- Validate student details
- Responsive web interface

## Requirements
- Node.js installed on your computer

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run `npm start`.
4. Open http://localhost:3000 in your browser.

## Project Structure
- `server.js` — Node.js server and API
- `public/index.html` — Web page
- `public/style.css` — Styling
- `public/app.js` — Frontend functionality

## Note
Student data is stored in memory and resets when the server restarts. This is a learning project; it does not use a database.
